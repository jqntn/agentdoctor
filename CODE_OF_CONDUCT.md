# Code of conduct

Be professional. Critique config, code, and rules — not people. No harassment, no
discrimination, no bad-faith participation. Disagreements about rules are settled with
reproducible cases: a config file that shows the false positive or the missed finding beats
any amount of argument.

Report conduct issues privately to the maintainer via the contact on the GitHub profile.
Reports are handled confidentially. The maintainer may warn, moderate, or ban at their
discretion.
